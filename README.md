# Beyond Consistency: Preserving Temporal Structure in Zero-Shot Video Editing

## Overview
We propose a novel zero-shot video editing framework that explicitly preserves the source video’s temporal structure, going beyond simple temporal consistency.

## Features
- Adaptive video partition & anchor frame selection
- Clip-adaptive token merging
- Alternated Combination of Adjacent Clips

## Installation
```bash
git clone https://github.com/Beyond-Consistency/Beyond-Consistency-TSPVE-Code.git
cd Beyond-Consistency-TSPVE-Code
pip install -r requirements.txt
```
## Usage
```bash
python run_vidtome.py --config xxx.yaml
```
